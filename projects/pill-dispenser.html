Project

Pill Dispenser

A custom built machine designed to dispense a pill at set intervals using a Python controlled stepper motor.

Overview

This group project focused on creating a physical pill dispensing prototype. The system uses a windmill shaped centerpiece controlled by a stepper motor. When the centerpiece rotates over an opening, a pill can pass through and be released into the chamber.

My contribution

My main responsibility was soldering and working with the circuit boards. This gave me practical experience with assembling electronic components and understanding how physical parts, electrical connections, and software control work together in a functioning system.

What I learned

I learned more about building technical systems from scratch, how components interact, and how important reliable physical connections are when software depends on hardware behaving correctly.
